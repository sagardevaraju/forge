# FORGE v0.1.0 — Initial Zenodo release

**Release date:** 2026-05-24
**DOI:** [10.5281/zenodo.20368096](https://doi.org/10.5281/zenodo.20368096)
**License:** CC-BY-4.0 (dataset + documentation)

FORGE is a **scenario-coupled catastrophe-operations console** for primary
insurers and reinsurers. A single Monte-Carlo scenario set drives three
optimization layers simultaneously — a Portfolio MIP, an Operational LP
for adjuster routing, and a claims pre-flagger — through a shared Decision
Reconciler. This is the first release archived to Zenodo for permanent
citability.

## What's in this release

### Optimization stack

- **Portfolio MIP** (`api_py/optimize_portfolio.py`) — PuLP + CBC,
  11-action rate grid (retain · 7-bucket reprice · non-renew · cede QS ·
  cede XS), per-cohort retention elasticity, TVaR-99 capital constraint
  computed scenario-by-scenario over K = 1000 lognormal draws per cohort.
- **Operational LP** — VRP-style adjuster routing across freshly-opened
  claims.
- **Claims pre-flagger** — early-warning surface against the same
  scenario set used by the MIP.
- **Decision Reconciler** (`lib/reconciler/index.ts`) — joins the three
  layers' outputs and surfaces conflicts to the operator.

### Multi-peril scenario engine

Five Monte-Carlo perils, each calibrated to published anchors:

| Peril | Source(s) |
|---|---|
| Hurricane | HURDAT2 best-track + NHC cone climatology |
| Severe-convective-storm (hail) | TORRO + Brooks 2003 hailstorm climatology |
| Wildfire | NIFC + CA-DINS perimeter sets |
| Earthquake | Gutenberg-Richter (Hauksson 2011) + Bakun-Wentworth MMI |
| Winter storm | NWS WSSI + TDI 2022 Uri report + Karen Clark Buffalo |

Hurricane covers Atlantic + Gulf, with Caribbean and Atlantic-Canada
basin tracks shipped in v0.1.0.

### Treaty layer engine

Schema version 5, backward-compatible. Variants supported:

- Quota share (QS)
- Excess-of-loss (XS) with per-occurrence reinstatement modeling
- Fronting (with premium-cession economics)
- Captive (trapped vs free capital accounting)
- ILS / cat-bond (indemnity-trigger v1)

### Decision lifecycle

- Versioned decision ledger with column-level WORM (write-once-read-many)
  on content fields; lifecycle columns (`notices_sent_at`, `executed_at`,
  `reversed_at`, `reversed_by`) remain freely mutable.
- Decision rollback with `manual_reversal_required` warnings.
- `/audit` view with diff + filters + pagination.
- Quarterly post-mortem job (`scripts/postmortem.py` + GHA cron).
- Concurrent decision queue with row-level locking via separate
  `decisions_queue` table.

### Reproducibility

- **Dockerfile** with pinned `node:24.7.0` + `python:3.12.7` + `coinor-cbc`
  + `libgeos`. Multi-stage build; CPU-only image.
- **Pinned `requirements.txt`** for runtime; offline `requirements-train.txt`
  for the CV head (not bundled into the Vercel function).
- **Gebru-datasheet-format dataset card** (`docs/DATASET_CARD.md`) with
  full provenance, schema, and column-by-column documentation.
- **Calibration citations** in `research.md` — every numeric value in
  `PERIL_SCALES`, `_PERIL_LEVEL_MULT`, and `HAZUS_MATRIX` traces to a
  published source.

### Privacy

- **Presidio-backed PII classifier** (`lib/book/pii_classifier.ts` +
  `api_py/pii_classifier.py`) replacing the original regex deny-list.

### Visualization

- TopoJSON state choropleth at scale with per-state aggregates.
- Real Sentinel-2 chip pipeline (Microsoft Planetary Computer) feeding
  band-math-derived CV features for the property drill-down.

## Test posture

- **vitest:** 764 passed + 1 documented skip (`reoptimize.test.ts` gated
  behind `FORGE_SKIP_REOPTIMIZE_INTEGRATION=1` for loaded dev DBs)
- **pytest:** 418 passed + 1 documented pre-existing failure
  (`test_precompute_with_sims.py::test_include_sims_actually_modifies_cohort_losses`)
- **xgb segfault test** ignored per the autonomous-execution charter

## What's NOT in this release

- **Authentication + multi-tenancy.** Deferred to a future
  real-customer-rollout phase. Operator identity is currently captured
  via an `X-Forge-Operator` header with `'demo_operator'` fallback;
  Clerk / RBAC / `tenant_id` / two-person rule / SOC 2 audit wiring are
  all scaffolded but parked.
- **NHC track-error climatology + USGS NED elevation overlay** for the FL
  coastal demo track. Rescoped as a future product feature.
- **OSF preregistration for the user study.** The study protocol ships
  as `docs/USER_STUDY_PROTOCOL.md` as a design document; if FORGE later
  pursues academic submission, it's the paste-ready basis for an OSF
  preregistration at that point.

## Getting started

```bash
git clone https://github.com/sagardevaraju/forge.git
cd forge
npm install
pip install -r requirements.txt
npm run migrate
python scripts/seed_policy_book.py
python -m scripts.precompute_portfolio_optimization
npm run dev   # http://localhost:3000
```

See [`CLAUDE.md`](../../CLAUDE.md) for the full build / test cheatsheet,
[`DEMO.md`](../../DEMO.md) for the demo walkthrough, and
[`docs/DATASET_CARD.md`](../DATASET_CARD.md) for the dataset
documentation.
