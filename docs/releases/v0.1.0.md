# FORGE v0.1.0 — Initial Zenodo release

**Release date:** 2026-05-24
**DOI:** [10.5281/zenodo.20368096](https://doi.org/10.5281/zenodo.20368096)
**License:** CC-BY-4.0 (dataset + documentation)

FORGE is a scenario-coupled catastrophe-operations console for primary
insurers and reinsurers. One Monte-Carlo scenario set drives three
optimization layers in parallel: a Portfolio MIP, an Operational LP for
adjuster routing, and a claims pre-flagger. A shared Decision Reconciler
joins their outputs and flags cross-layer conflicts. v0.1.0 is the first
release archived to Zenodo with a citable DOI.

## What's in this release

### Optimization stack

- **Portfolio MIP** (`api_py/optimize_portfolio.py`). PuLP + CBC over an
  11-action rate grid (retain, 7-bucket reprice, non-renew, cede QS, cede
  XS), with per-cohort retention elasticity. The TVaR-99 capital constraint
  is computed scenario-by-scenario over K = 1000 lognormal draws per cohort.
- **Operational LP.** VRP adjuster routing across open claims.
- **Claims pre-flagger.** Runs against the same scenario set the MIP uses
  and tiers policies by expected severity.
- **Decision Reconciler** (`lib/reconciler/index.ts`). Joins the three
  layers' outputs and flags conflicts for the operator.

### Multi-peril scenario engine

Five Monte-Carlo perils, each calibrated against published sources:

| Peril | Source(s) |
|---|---|
| Hurricane | HURDAT2 best-track + NHC cone climatology |
| Severe-convective-storm (hail) | TORRO + Brooks 2003 hailstorm climatology |
| Wildfire | NIFC + CA-DINS perimeter sets |
| Earthquake | Gutenberg-Richter (Hauksson 2011) + Bakun-Wentworth MMI |
| Winter storm | NWS WSSI + TDI 2022 Uri report + Karen Clark Buffalo |

Hurricane covers Atlantic + Gulf. Caribbean and Atlantic-Canada basin
tracks shipped in v0.1.0 (P3.18).

### Treaty layer engine

Schema version 5, backward-compatible. Variants supported:

- Quota share (QS)
- Excess-of-loss (XS) with per-occurrence reinstatement modeling
- Fronting (with premium-cession economics)
- Captive (trapped vs free capital accounting)
- ILS / cat-bond (indemnity-trigger v1)

### Decision lifecycle

- Versioned decision ledger with column-level WORM (write-once-read-many)
  on content fields. Lifecycle columns (`notices_sent_at`, `executed_at`,
  `reversed_at`, `reversed_by`) remain mutable.
- Decision rollback with `manual_reversal_required` warnings.
- `/audit` view with diff, filters, and pagination.
- Quarterly post-mortem job (`scripts/postmortem.py` + GHA cron).
- Concurrent decision queue with row-level locking via a separate
  `decisions_queue` table.

### Reproducibility

- Dockerfile pins `node:24.7.0`, `python:3.12.7`, `coinor-cbc`, and
  `libgeos`. Multi-stage build, CPU-only.
- Pinned `requirements.txt` for runtime. Offline `requirements-train.txt`
  holds the CV-head training deps and is not bundled into the Vercel
  function.
- Dataset card at `docs/DATASET_CARD.md` follows the Gebru-datasheet
  format with full provenance, schema, and column-by-column docs.
- Calibration citations in `research.md`. Every value in `PERIL_SCALES`,
  `_PERIL_LEVEL_MULT`, and `HAZUS_MATRIX` has a published source.

### Privacy

- Presidio-backed PII classifier (`lib/book/pii_classifier.ts` +
  `api_py/pii_classifier.py`). Replaces the regex deny-list that shipped
  originally.

### Visualization

- TopoJSON state choropleth with per-state aggregates.
- Sentinel-2 chip pipeline via Microsoft Planetary Computer. The property
  drill-down reads band-math CV features computed from those chips.

## Test posture

- **vitest:** 764 passed + 1 documented skip (`reoptimize.test.ts` gated
  behind `FORGE_SKIP_REOPTIMIZE_INTEGRATION=1` for loaded dev DBs)
- **pytest:** 418 passed + 1 documented pre-existing failure
  (`test_precompute_with_sims.py::test_include_sims_actually_modifies_cohort_losses`)
- **xgb segfault test** ignored per the autonomous-execution charter

## What's NOT in this release

- Authentication and multi-tenancy. Deferred until the first
  real-customer rollout. Operator identity is currently captured via an
  `X-Forge-Operator` header with a `'demo_operator'` fallback. Clerk,
  RBAC, `tenant_id`, the two-person rule, and SOC 2 audit wiring are
  scaffolded but parked.
- NHC track-error climatology and USGS NED elevation overlay for the FL
  coastal demo track. Rescoped as a future product feature; scoping doc
  at `docs/scoping/audit-3-nhc-track-error-usgs-ned.md`.
- OSF preregistration for the user study. The protocol ships as
  `docs/USER_STUDY_PROTOCOL.md` for now; it's paste-ready if FORGE later
  pursues academic submission.

## Getting started

```bash
git clone https://github.com/sagardevaraju/forge.git
cd forge
npm install
pip install -r requirements.txt
npm run migrate
python scripts/seed_policy_book.py
python -m scripts.precompute_portfolio_optimization
npm run dev   # http://localhost:3000
```

See [`CLAUDE.md`](../../CLAUDE.md) for the full build / test cheatsheet,
[`DEMO.md`](../../DEMO.md) for the demo walkthrough, and
[`docs/DATASET_CARD.md`](../DATASET_CARD.md) for the dataset
documentation.
