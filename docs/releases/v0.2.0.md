# FORGE v0.2.0 — AUDIT.3 calibration release

**Release date:** 2026-05-24
**DOI:** [10.5281/zenodo.20370031](https://doi.org/10.5281/zenodo.20370031)
**License:** CC-BY-4.0 (dataset + documentation), MIT (code)

This release closes AUDIT.3 — the audit-finding cluster that flagged
hand-coded placeholder values in the hurricane scenario generator
(`_DEMO_TRACK_FL` track waypoints, `_COASTAL_ZIP3S` lat/lon/elevation
table, the linear-ramp track-error σ, the flat-15-mph wind-error σ).
Every numeric input to the hurricane Monte Carlo now traces to a
published source.

## What changed

### Calibration sources now backing the hurricane scenarios

| Input | v0.1.0 | v0.2.0 |
|---|---|---|
| Track-error σ per forecast hour | Linear ramp to 2.5°/120 h, hand-set | Derived from NHC OFCL verification climatology (1989-2023), reconstructs the published 2026 NHC Atlantic cone within 10% at hours 24/48/72/96/120 |
| Intensity-error σ | Flat 15 mph regardless of horizon | NHC OFCL signed peak-wind σ, 21.55 kt → 24.80 mph at 120 h |
| Seed track shape | Hand-tabulated 21-waypoint Cat-4 FL-west-coast composite | Hurricane Ian (2022), pulled from the committed HURDAT2 parquet |
| Coastal ZIP3 catalog | 15 hand-picked ZIP3s with eyeball-estimated lat/lon and elevation | 38 ZIP3s in coastal states with ≥ 50 policies; centroids from policy AVG, elevations from USGS NED 1/3-arcsec via EPQS |

### New scripts (regeneration commands)

| Script | Output | Cost |
|---|---|---|
| `python -m scripts.fetch_nhc_errors` | `artifacts/nhc/{track_error,intensity_error}.json` | ~10 s (cached zips) |
| `python -m scripts.extract_elevations` | `policies.elevation_m` column in local DB | ~3-5 h for 10k policies (EPQS rate-limited) |
| `python -m scripts.precompute_coastal_zip3s` | `artifacts/coastal_zip3s.json` | ~80 s (~38 EPQS calls) |

The two precompute outputs are committed (regenerable, deterministic
given the seeded book + EPQS endpoint state).

### Impact on portfolio MIP outputs

Re-running `python -m scripts.precompute_portfolio_optimization`
against the new calibration shifts every aggregate metric by less
than 2% — consistent with the scoping doc prediction that the
FL-coast book is small and the prior hand-coded numbers were roughly
right by eyeball:

| Metric | v0.1.0 | v0.2.0 | Δ |
|---|---:|---:|---:|
| Objective ($) | 32,319,678 | 32,314,040 | -0.02% |
| Book p99 loss ($) | 17,680,625 | 17,542,677 | -0.78% |
| Book TVaR-99 ($) | 18,193,340 | 18,393,155 | +1.10% |
| Retained TVaR-99 ($) | 12,455,083 | 12,608,193 | +1.23% |
| Capital budget ($) | 27,246,959 | 27,178,878 | -0.25% |
| reprice_p20 cohorts | 172 | 165 | -4.1% |
| cede_xs cohorts | 388 | 395 | +1.8% |
| non_renew cohorts | 10 | 10 | 0 |

7 cohorts shifted from reprice_p20 → cede_xs. The action mix
qualitatively unchanged.

### Verification gates met (scoping doc §5)

1. **No hand-coded waypoints or elevations remain in `ml/scenarios/generate.py`.** `grep -nE '_DEMO_TRACK_FL|_COASTAL_ZIP3S' ml/scenarios/generate.py` returns nothing.
2. **The reconstructed cone of uncertainty** for a 5-day forecast matches the empirical NHC cone within 10% at hours 24/48/72/96/120 (`test_scenarios_reconstruct_nhc_cone_within_10_percent`).
3. **Per-ZIP3 elevations** distribute realistically: coastal FL ZIP3s in 0-10 m (e.g., Naples 341 at -1.2 m), mountain inland NC ZIP3s at 600+ m (Asheville 287 at 631.5 m).
4. **All existing tests still pass + new tests for each phase.** vitest 767 + pytest 510 (vs 767 + 438 at v0.1.0 — net +72 new tests across AUDIT.3 Phases 1-4).
5. **Joint multi-peril TVaR-99 artifact regenerates cleanly** under the new elevation data (see "Impact on portfolio MIP outputs" above).

## What's NOT in this release

Carried forward from v0.1.0 — still parked, no scope change in v0.2.0:

- **Authentication + multi-tenancy.** Operator identity stays on the
  `X-Forge-Operator` header with the `'demo_operator'` fallback.
- **Auth-tied audit wiring (SOC 2 §CC7.2).** Scaffolded but parked.
- **OSF preregistration for the user study.** `docs/USER_STUDY_PROTOCOL.md`
  still ships as a design document.
